AUDIO VALIDATION BOUNDARY
=========================
The automated suite verifies the WebAudio graph and the intended gain/compression
configuration, but a headless browser cannot measure sound pressure level from a
physical phone speaker. The old root cause was deterministic in code: a 0.32
master gain was followed by very small synthesized music levels, including notes
around 49-65 Hz that phone speakers reproduce poorly.

1.3.1 raises the coarse-pointer/mobile master target to 0.78, applies modest
per-tone mobile boosts, shifts musical notes below 75 Hz up one octave on mobile,
and uses a DynamicsCompressor to control summed peaks. Final perceived loudness
must still be checked on actual phone hardware at a normal system-volume setting.

BACKEND SECURITY AND MODE VALIDATION
====================================
The Supabase production project was validated after adding first-class Endless
mode:

- RLS remains enabled on backend-only player/session/telemetry/rate-limit tables.
- Anonymous/authenticated roles have no access to those backend-only tables.
- Anonymous access to `runs` remains SELECT only.
- Direct anonymous leaderboard INSERT/UPDATE/DELETE remains revoked.
- Run writes go through the `game-session` Edge Function.
- The deployed Edge Function is version 3.
- The function accepts exactly Standard, Endless, and Daily run modes.
- Standard and Daily submissions are limited to the nine-sector objective.
- Endless submissions may progress beyond sector 9 and cannot claim a victory
  state.
- A separate Endless score index and leaderboard filter are present.
- When a browser supplies its first real callsign, prior community rows for the
  same anonymous player identity still named PILOT can be relabeled server-side.
- The function validates the public application key, session token hash, active
  session, run-shape constraints, elapsed time sanity, duplicate run IDs, broad
  score bounds, and request rate limits.
- Only a coarse platform label is stored rather than a raw browser user-agent.
- Supabase Security Advisor reports zero security findings after the Endless
  migration.

LIMITATIONS
===========
This is strong automated release validation, not a claim of universal bug-free
operation. Chromium emulates the phone input/runtime surface; it is not a
substitute for listening to the game on a physical iPhone or Android speaker.
Safari/WebKit and every browser-management/accessibility configuration are also
not individually certified.

The leaderboard is hardened against casual direct-database score fabrication but
the game remains client-authoritative. It is not a fully server-simulated or
cryptographically provable competitive environment.
