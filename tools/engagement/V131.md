# Neon Rift 1.3.1

Patch release focused on phone audio and clearer game entry.

- Raises the mobile WebAudio mix and adds dynamics compression to control summed peaks.
- Lifts very low musical bass notes on coarse-pointer/mobile devices so phone speakers can reproduce them more effectively.
- Prompts an unnamed player for a callsign before the first Standard, Endless, or Daily run.
- Preserves the local anonymous browser identity and backfills prior default `PILOT` leaderboard rows when the player first supplies a real callsign.
- Exposes Standard Run, Endless Run, and Daily Signal as distinct home-screen choices.
- Adds a separate verified all-time Endless leaderboard.
- Keeps Standard victory -> Endless continuation, but labels that same-build continuation unranked.
- Adds browser regression coverage for onboarding, mode separation, post-win Endless UX, and the new audio graph.
- No seasons or seasonal resets.
